# Общие сведения

Adversarial Attack — это атака на модель машинного обучения, при которой злоумышленник создаёт специально модифицированные входные данные (adversarial examples), которые:
- визуально неотличимы от оригинальных данных для человека.
- заставляют модель делать ошибочные предсказания.

Одной из атак является Fast Gradient Method (FGSM). Принцип работы FGSM
1.	Вычислить градиент функции потерь про входным данным (не по весам!): ΔxJ (θ, x, y)
2.	Определяется направление наискорейшего роста потерь: sign (Δx J )
3.	Создается adversarial-пример x adv = x + ε sign (Δx J )
Параметр: $ε$ (epsilon) – величина возмущения (обычно принимается от 0.01 до 0.3), чем больше значение ε, тем сильнее атака, но заметнее изменения.

Формула:

Методы защиты

|Метод|Описание|Плюсы|Минусы|
|:-:|:-:|:-:|:-:|
|Adversarial training|Обучение на adversarial примерах|Высокая эффективность|Долгое временя обучения|
|Input preprocessing|Сглаживание, квантование входных данных|Простота реализации|Может снизить точность на чистых данных|
|Gradient masking|Сокрытие градиентов|Затрудняет атаку|Не надежная защита|
|Defensive distillation|Обучение с «мягкими» метками|Устойчивость к шумам|Сложность реализации|
