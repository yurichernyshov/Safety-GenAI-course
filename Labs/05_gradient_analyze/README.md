# Общие сведения

Вектор градиента направлен в направлении наискорейшего роста функции нескольких переменных. Это свойство градиента используется при обучении нейронных сетей, а именно, для уменьшения функции ошибки с помощью оптимизации значений весов нейронов. 
При обучении нейронной сети каждый батч данных производит градиенты — векторы, показывающие направление обновления весов. 
Отравленные данные создают аномальные градиенты:
- по величине градиентов, градиенты от отравленных примеров значительно больше или меньше нормы,
- по направлению градиентов, градиенты отравленных данных противоречат градиентам чистых данных, задавая неправильное направление для обновления весов,
-	по статистическим характеристикам градиентов, статистическое распределение градиентов на отравленных данных отличается от обычного поведения на нормальных данных.
Для обнаружения отклонения от нормального поведения используются численные метрики, позволяющие сравнить аномальное и нормальное поведение: норма градиента, косинусное расстояние для направления градиентов, дисперсия градиентов.
