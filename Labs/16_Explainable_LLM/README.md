Объяснимый ИИ (XAI) для LLM делится на два основных подхода:
1.	Пост-хок анализ (Post-hoc): Анализ уже обученной модели без изменения её весов.
a.	Attention Visualization: Показывает, на какие токены входной последовательности модель "смотрела" при генерации ответа.
b.	Saliency Maps: Показывает важность входных токенов для конкретного выхода через градиенты.
2.	Поведенческий анализ (Behavioral):
a.	Prompt Sensitivity: Насколько сильно меняется ответ при незначительном изменении запроса.
b.	Entropy/Confidence: Анализ распределения вероятностей следующего токена. Высокая энтропия часто указывает на неуверенность (риск галлюцинации).
Контроль работы LLM:
•	Использование метрик объяснимости позволяет выявлять:
•	Галлюцинации: Модель уверенно генерирует факт, но энтропия высока или внимание расфокусировано.
•	Bias (Смещение): Модель реагирует на чувствительные токены (пол, раса) непропорционально сильно.
•	Prompt Injection: Аномальные паттерны внимания на служебные символы.

Задача 1. Базовый инференс и анализ логитов
Цель: Получить доступ к вероятностям генерации токенов.
Загрузите небольшую инструктивную модель (например, TinyLlama/TinyLlama-1.1B-Chat-v1.0 или google/flan-t5-small для экономии памяти).
Сформулируйте фактологический вопрос (например, "Столица Франции?").
Получите топ-5 наиболее вероятных токенов для первого шага генерации.
Вычислите энтропию распределения вероятностей топ-10 токенов.

import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
import numpy as np
model_name = "TinyLlama/TinyLlama-1.1B-Chat-v1.0"
tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForCausalLM.from_pretrained(model_name, device_map="auto", torch_dtype=torch.float16)
prompt = "<|user|>\nСтолица Франции?<|assistant|>\n"
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)

with torch.no_grad():
    outputs = model(**inputs)
    logits = outputs.logits[:, -1, :] # Логиты следующего токена
    probs = torch.softmax(logits, dim=-1)
    
    # Топ-5 токенов
    top_probs, top_indices = torch.topk(probs, 5)
    
    # Энтропия
    entropy = -torch.sum(probs * torch.log2(probs + 1e-9)).item()

print("Топ токены:", tokenizer.batch_decode(top_indices))
print("Энтропия:", entropy)

import seaborn as sns
import matplotlib.pyplot as plt

# Перегенерация с вниманием
outputs = model(**inputs, output_attentions=True)
attentions = outputs.attentions[-1][0] # Берем последний слой, первый батч
# Усредняем по всем головам внимания для упрощения
avg_attention = attentions.mean(dim=0).cpu().numpy()

# Токены
tokens = tokenizer.convert_ids_to_tokens(inputs['input_ids'][0])

plt.figure(figsize=(10, 8))
sns.heatmap(avg_attention, xticklabels=tokens, yticklabels=tokens, cmap='viridis')
plt.title("Attention Map (Last Layer Averaged)")
plt.show()

Задача 3. Анализ устойчивости (Prompt Perturbation)
Цель: Проверить, насколько модель чувствительна к шуму (Control for Robustness).

from sklearn.metrics.pairwise import cosine_similarity
def get_last_hidden_state(text):
    inputs = tokenizer(text, return_tensors="pt").to(model.device)
    with torch.no_grad():
        outs = model(**inputs, output_hidden_states=True)
    # Берем последнее скрытое состояние последнего токена
    return outs.hidden_states[-1][0, -1, :].cpu().numpy()

q1 = "Как приготовить борщ?"
q2 = "Как сварить борщ?" # Синоним

emb1 = get_last_hidden_state("<|user|>\n" + q1 + "<|assistant|>\n")
emb2 = get_last_hidden_state("<|user|>\n" + q2 + "<|assistant|>\n")

similarity = cosine_similarity([emb1], [emb2])[0][0]
print(f"Схожесть представлений ответов: {similarity:.4f}")
