# Материалы учебного курса "Объяснимый и безопасный искусственный интеллект"

Автор: Чернышов Юрий Юрьевич, к.ф.-м.н., доцент УНЦ "Искусственный интеллект" ИРИТ-РТФ УрФУ.

ВАЖНОЕ ПРЕДУПРЕЖДЕНИЕ ОБ ЭТИКЕ И БЕЗОПАСНОСТИ

Материалы курса предназначены исключительно для образовательных целей в рамках изучения методов защиты ИИ-систем. 

Все эксперименты в лабораторных работах курса должны проводиться:
- Только в изолированных тестовых средах (локальные модели, sandbox)
- Без воздействия на производственные системы или публичные API
- С соблюдением принципов ответственного раскрытия уязвимостей 
- Под руководством преподавателя и с предварительным согласованием методики

При изучении материалов и их применении не забывайте руководствоваться действующими требованиями законодательства

УК РФ ст. 272: Неправомерный доступ к компьютерной информации

УК РФ ст. 273: Создание, использование и распространение вредоносных компьютерных программ

УК РФ ст. 274: Нарушение правил эксплуатации средств хранения, обработки или передачи компьютерной информации и сетей
